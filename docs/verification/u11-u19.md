scoped four-state reasoning, bounded invoking-host interpretation, independent
artifact validation and human authority. Implement related work together, delegate
bounded modules, verify focused changes, and run broader checks at G4/G5.

history/recovery. The review agent then handled renderer regression coverage;
root integrated renderers, Stage 07 and the public supervisor. An Astra high

framework was introduced.
